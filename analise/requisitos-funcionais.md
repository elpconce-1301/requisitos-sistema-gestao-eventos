# Requisitos Funcionais

1. O sistema deve permitir que participantes visualizem todos os eventos disponíveis.
2. O sistema deve permitir que participantes façam inscrição em eventos e workshops.
3. O sistema deve permitir que participantes cancelem sua inscrição sem contato direto com a organização.
4. O sistema deve permitir que participantes emitam certificados após o evento.
5. O sistema deve permitir que organizadores criem e configurem eventos com informações de vagas, datas, horários e preço.
6. O sistema deve controlar automaticamente o número de vagas de cada evento.
7. O sistema deve permitir que organizadores acompanhem a quantidade de inscritos em tempo real.
8. O sistema deve permitir que organizadores definam se um evento aceita ou não cancelamento de inscrição.
9. O sistema deve permitir que a equipe financeira confirme pagamentos antes de liberar determinadas inscrições.
10. O sistema deve diferenciar eventos gratuitos de eventos pagos.
11. O sistema deve permitir que a equipe financeira controle reembolsos quando aplicável.
12. O sistema deve permitir que palestrantes consultem a programação dos eventos e a lista de participantes de suas atividades.
13. O sistema deve permitir que participantes possam se inscrever em vários workshops no mesmo dia, respeitando conflitos de horário.
14. O sistema deve oferecer lista de espera quando o evento estiver lotado.
15. O sistema deve enviar comprovantes de inscrição aos participantes (informação identificada como desejada no documento).
