# Requisitos Não Funcionais

1. O sistema deve ser acessível via navegador web.
2. O sistema deve garantir disponibilidade adequada para consulta de eventos e inscrições durante o horário comercial.
3. O sistema deve proteger os dados pessoais dos participantes e respeitar a privacidade das informações.
4. O sistema deve apresentar desempenho suficiente para carregar a lista de eventos em poucos segundos.
5. O sistema deve ser compatível com dispositivos móveis e desktop.
6. O sistema deve registrar e controlar autenticação dos perfis de usuário (organizador, participante, equipe financeira, palestrante).
7. O sistema deve permitir auditoria de ações críticas, como cancelamento de inscrição e confirmação de pagamento.
8. O sistema deve manter integridade dos dados de vagas e inscrições em situações de concorrência de acesso.
