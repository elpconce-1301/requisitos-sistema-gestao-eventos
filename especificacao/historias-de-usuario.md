# Histórias de Usuário

## 1. Participante
- Como participante, quero visualizar todos os eventos disponíveis em um único lugar para escolher em quais me inscrever.
- Como participante, quero me inscrever em eventos e workshops para garantir minha participação.
- Como participante, quero cancelar minha inscrição sem precisar entrar em contato com a organização para ter autonomia.
- Como participante, quero emitir meu certificado após o evento para comprovar minha participação.
- Como participante, quero receber um comprovante logo após a inscrição para ter confirmação imediata.

## 2. Organizador
- Como organizador, quero criar eventos e definir vagas, horários e políticas de cancelamento para gerenciar melhor a programação.
- Como organizador, quero acompanhar a quantidade de inscritos em tempo real para tomar decisões de controle de vagas.
- Como organizador, quero ativar lista de espera para eventos lotados para atender mais interessados.

## 3. Equipe Financeira
- Como membro da equipe financeira, quero confirmar pagamentos antes de liberar inscrições pagas para evitar reservas indevidas.
- Como membro da equipe financeira, quero controlar reembolsos quando aplicável para manter a gestão financeira correta.

## 4. Palestrante
- Como palestrante, quero consultar a programação das atividades das quais participo para me preparar.
- Como palestrante, quero consultar a lista de participantes inscritos em minhas atividades para conhecer meu público.
