# Critérios de Aceitação

## Inscrição em Evento
- Deve permitir inscrição quando houver vagas disponíveis.
- Deve enviar comprovante de inscrição após a confirmação.
- Deve incluir o participante na lista de espera se o evento estiver lotado.

## Cancelamento de Inscrição
- Deve permitir cancelamento quando o evento permite essa ação.
- Deve impedir cancelamento quando a política do evento não autoriza.
- Deve liberar a vaga para outro participante após o cancelamento.

## Confirmação de Pagamento
- Deve liberar a inscrição somente após a confirmação do pagamento em eventos pagos.
- Deve manter inscrição pendente enquanto o pagamento não for confirmado.

## Emissão de Certificado
- Deve permitir emissão de certificado para eventos concluídos.
- Deve disponibilizar o certificado para download ou visualização.

## Consulta de Palestrantes
- Deve permitir que palestrantes vejam somente sua programação.
- Deve permitir que palestrantes consultem a lista de inscritos em suas atividades.
